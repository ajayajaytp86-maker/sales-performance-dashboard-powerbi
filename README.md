# 📊 Sales Performance Dashboard 2025

## 📌 Project Overview

This project is an **Interactive Sales Performance Dashboard** built using **Power BI** to analyze business sales data for the year 2025.
The dashboard provides insights into **total sales, profit, orders, product categories, and regional performance**.

It helps businesses quickly understand trends, identify top-performing products, and analyze regional sales distribution.

---

## 🚀 Features

* 📈 Monthly Sales Trend Analysis
* 💰 Total Sales and Profit Overview
* 📦 Sales by Product Category
* 🌍 Sales Distribution by Region
* 🏆 Top 5 Products by Profit
* 📊 Profit Distribution by Region
* 🎛 Interactive Filters (Date, Category, Region)
